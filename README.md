# 🎮 Flappy Oktay Kayacan

Mobil cihazlar için optimize edilmiş **Flappy Bird** tarzı oyun! 📱

## 🎯 Oyun Hakkında

Oktay Kayacan'ın adı taşıyan bu oyunda:
- **Kuşu kontrol et** ve **boruları geç**
- Her başarılı geçiş = **+1 puan**
- Duvardan veya boruya çarpma = **Oyun Bitti**
- **Puan kaydedil** ve oyuna devam et!

## 🕹️ Kontroller

| Platform | Kontrol |
|----------|---------|
| 📱 **Mobil** | Ekrana **dokunun** |
| 💻 **PC** | **Click** veya **SPACE tuşu** |

## 🚀 Nasıl Oynanır?

1. GitHub repo'ya giderek **`index.html`** dosyasını indir
2. Tarayıcıda aç (HTML dosyasına çift-tıkla)
3. Ekrana dokunun/tıklayın ve oyunun başlamasını sağlayın
4. Boruların arasından geçerek puan kazanın!

## 🎮 Oyun Mekanikleri

- **Yerçekimi**: Kuş sürekli düşer
